# Live2D 视频通话

在「角色设定 → Live2D」选择 ZIP 或模型文件夹。上传成功后可以预览表情、挥手、点头、摇头和模型的姿势，并修改每种情绪对应的表情、动作与姿势。在聊天页点击视频按钮、输入栏的「视频通话」，或现有通话的「开启视频」，即可进入。

支持包含 `.model3.json`、`.moc3`、纹理和被引用的表情、动作、物理、姿势文件的 Cubism 3/4/5 包。ZIP 可以包含顶层文件夹及 PSD、CMO3、源码等其他文件；只解压实际引用的运行文件。模型文件夹里没写进 `.model3.json` 的动作（`.motion3.json`）和表情（`.exp3.json`）也一并读进来（读不了的跳过，不影响上传）。多个模型的包需要先分成单模型包。运行资源保存在此设备的 IndexedDB `live2d` 表，角色只保存元数据和映射；在其他设备使用时需重新上传。新模型通过解析、Core、纹理及首帧检查并保存成功后才替换原模型。

视频沿用 `useVoiceCall` 的语音识别、流式对话、语音合成、打断、输入方式和通话记录。背景取该角色当前节律时段的地点，缺少节律时取角色地点，再回退到房间；时段使用环境设置的 IANA 时区。背景仍使用现有 `SceneBackdrop` 场景插画。

人物按每份模型实际可见的轮廓等比适配并贴住画面底部。加载或换装时先在中立姿势测量可见网格，再用一次小画面的 alpha 读取去除纹理留白；不依赖导出画布的尺寸或原点。轮廓按衣着缓存，动作播放时不会不断缩放、上下抖动。横竖屏变化重新计算投影；字幕覆盖在人物前方，不再把人物画面隔在字幕上面。角色设定中的「人物大小」「左右」「上下」在自动取景上微调并保存（`live2d.framing`：大小以底边中点为基准缩放，位置按画面宽高的百分比平移）。视频通话右上角的「调位置」对着通话画面直接调同一份数据：一根手指或鼠标拖动，两指捏合或滚轮缩放，也能拉滑块，点「好了」收起。

「角色设定 → Live2D → 默认衣着」决定无匹配时穿哪套。通话读取当前节律活动对应的日常、运动、睡衣或约会衣着，按名称优先、匹配词其次选择模型内的服装；没有匹配项或没有节律衣着时使用保存的默认项。斑 v19 自动识别「铠甲」「族服」，两套都保持挥手、抱臂和表情动作。普通模型识别离散换装参数；也可在「衣着匹配与模型参数」新增衣着、填写匹配词并设置模型已有的换装参数。没有换装资源的模型保留原装。衣着预览独立于默认选择，旧上传在下次打开设置时自动补齐可用项。

嘴型使用 `playBytes.onAudioLevel`，由解码后的音频响度和实际播放进度驱动。字幕的模拟音量、麦克风输入不会驱动角色嘴型。暂停、等待音频、播放错误、取消和挂断归零，动作、表情、物理更新之后再次覆盖唇形以保证静默时闭嘴。无法解码响度时保持闭嘴。自动眨眼按模型 EyeBlink 分组，嘴型按 LipSync 分组；没有分组时尝试标准 Cubism 参数。

AI 继续使用现有 `[expr:smile]` 等情绪标签。自动映射模型实际导出的表情名称，用户可调整；当前说出的句子触发打招呼、赞同、否定（`live2d/cues.ts` 的 `dialogueCue`：问句不算回答，"你好像…""可不可以…"这类不触发）。

动作按文件名列出和识别（`rest-to-wave`、`nod`，不是 `Gesture:3`）：映射留在"自动"的，按分组名和文件名里的词去对（wave / nod / shake、挥手 / 点头 / 摇头……，`autoMotions`），设置页显示的"自动（…）"和通话里实际用的是同一套；名字带 idle 的轮流当待机动作。动作播完后，它动过的参数缓缓回到模型的默认值——待机动作只管自己那几个参数，否则点头、摇头之后头会一直歪着。

**姿势。** 斑 v19 的手臂在三种姿势之间连续运动：自然、抬手、抱臂（`live2d/outfits.ts` 的 `suggestedPoses`，由 `gesture.ts` 的连续控制器驱动，新的姿势直接改变目标，不排队）。它们是能保持的姿势，不是播一遍的动作，六段过渡片段（`rest-to-wave`……）不出现在动作列表里。用法有三层，前面的优先：

1. 视频通话的提示里列出可用姿势，AI 用 `[pose:抱臂]` 自己换（认 id、名字和别名；抬手是抬几秒后放下，自然、抱臂保持到下次换）。
2. 「表情与动作映射」最右一栏给每个表情、每个时刻指定姿势（`live2d.poseMap`）。表情管平时摆哪个；打招呼、赞同、否定是说到那句话时摆几秒再回来。
3. 留在"自动"的：打招呼抬手，否定抱臂，生气、嘟嘴抱臂，映射到冷淡、愠怒表情的情绪也抱臂，其余自然。

设置页有「预览姿势」按钮直接看这三种。其他模型没有姿势，使用导出的动作和配置映射。

**视线追踪。** 鼠标移到哪、手指按到哪，角色看向哪：瞳孔反应快，头小幅慢跟（斑沿用原运行库的幅度，其他模型用 Cubism 标准参数的幅度）。视线从眼睛实际所在的位置算起——加载时拨动眼球参数，看哪些网格跟着动来找眼睛，不依赖网格命名。鼠标移出窗口、手指抬起约一秒后看回正前方。「角色设定 → Live2D → 视线跟随鼠标和手指」可关。

```sh
pnpm typecheck
pnpm build
```
